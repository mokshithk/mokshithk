**› about this page**

Every graphic on this profile is self-generated inside this repository.
`ascii.svg` is an animated typing ASCII portrait rendered from an embedded
font subset. Daily stats are drawn natively via the GitHub GraphQL API
through a scheduled GitHub Action, committing only what changed. The
portrait animates with SMIL inside the SVG itself, since GitHub strips
scripts from READMEs — and since nothing loads from a third party,
nothing here can rate-limit or go dark.
